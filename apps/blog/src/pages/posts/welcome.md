# Welcome to Minions Prospecting

We're excited to introduce **Minions Prospecting** — Web search configs, prospect discovery rules, and lead scoring criteria.

## What's Included

- **TypeScript SDK**: `npm install @minions-prospecting/sdk`
- **Python SDK**: `pip install minions-prospecting`
- **CLI**: `npm install -g @minions-prospecting/cli`

Check out the [documentation](https://prospecting.minions.help) for a full guide.
