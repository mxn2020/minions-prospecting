---
title: Installation
description: Install Minions Prospecting packages
---

## TypeScript / Node.js

```bash
npm install @minions-prospecting/sdk minions-sdk
```

## Python

```bash
pip install minions-prospecting
```

## CLI

```bash
npm install -g @minions-prospecting/cli
```

## Requirements

- **Node.js** 20 or later
- **Python** 3.11 or later (for Python SDK)
