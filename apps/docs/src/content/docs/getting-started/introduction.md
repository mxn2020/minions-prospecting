# Minions Prospecting

Web search configs, prospect discovery rules, and lead scoring criteria

## Overview

This project is part of the [Minions ecosystem](https://github.com/mxn2020/minions) and provides:

- **TypeScript SDK** (`@minions-prospecting/sdk`) — Core library for Node.js
- **Python SDK** (`minions-prospecting`) — Python bindings
- **CLI Tool** (`@minions-prospecting/cli`) — Command-line interface
- **Web App** — Interactive playground at [prospecting.minions.wtf](https://prospecting.minions.wtf)
